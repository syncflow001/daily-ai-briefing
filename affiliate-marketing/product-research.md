# 상품 리서치 — 쿠팡파트너스 생활용품 (숏폼 전환 최적화)

> **목적:** "어떤 생활용품을 콘텐츠로 밀 것인가"를 데이터로 결정하는 프레임워크 + 검증용 시드 리스트 + 매주 반복 리서치 SOP
> **연결:** 마케팅 플랜 §8(Revenue) "세션 객단가 × 전환율" 레버의 실행 도구
> **버전:** v1 · 2026-07-28

---

## 0. 핵심 원칙 3가지 (리서치 전에 반드시)

숏폼 제휴에서 **상품 선정이 수익의 절반**입니다. 근거:

1. **세션 구매 특성** — 쿠팡파트너스는 내 링크 클릭 후 **세션 내 구매한 모든 상품**에 수수료가 붙습니다. 내가 소개한 3천원짜리가 아니라, 그 사람이 같은 세션에 산 10만원 무선청소기에도 커미션이 발생. → **"클릭을 유도하는 미끼 상품"과 "객단가를 올리는 환경"을 분리 설계.**
2. **생활용품 = 반복구매·낮은 구매저항·리뷰 신뢰** — 쿠팡 최대 카테고리. 단, **실사용 후기/장면이 전환을 좌우**. faceless여도 "실제 쓰는 장면(B롤)"이 핵심.
3. **로켓배송 = 즉시 전환** — "오늘 밤 주문하면 내일 옴"이 충동구매를 완성. 로켓배송/로켓와우 상품 우선.

---

## 1. 상품 선정 스코어링 (각 상품 후보를 이 표로 평가)

| 기준 | 배점 | 만점 조건 |
|------|:---:|-----------|
| **로켓배송 여부** | 0~3 | 로켓배송/로켓와우 = 3, 일반 = 1, 판매자배송 = 0 |
| **리뷰 신뢰도** | 0~3 | 리뷰 1천+ & 평점 4.5+ = 3 |
| **객단가 적정성** | 0~3 | 1~5만원(충동구매 스윗스팟) = 3, 너무 저가(수수료 미미) or 고가(구매저항) = 1 |
| **"영상성"(비주얼 임팩트)** | 0~3 | 15초에 "와" 나오는 before/after·사용컷 = 3 |
| **문제-해결 명확성** | 0~3 | 누구나 아는 불편을 해결 = 3 |
| **계절/시즌 적합** | 0~2 | 지금 시즌 수요 = 2 |
| **경쟁 포화도(역채점)** | 0~2 | 아직 숏폼에 덜 노출 = 2, 레드오션 = 0 |
| **합계** | **/19** | **13점 이상 = 콘텐츠 제작 후보** |

> 이 표는 자동화 파이프라인의 "2. 기획 단계"에 그대로 프롬프트로 넣을 수 있습니다 (Claude가 후보 상품을 이 기준으로 스코어링).

## 2. 유망 서브카테고리 맵 (생활용품 → 포맷 매핑)

생활용품을 5개 서브카테고리로 쪼개고, 각각을 faceless 포맷 5종(플랜 §4)에 매핑했습니다.

| 서브카테고리 | 대표 상품군 | 강점 | 최적 포맷 |
|------|------|------|------|
| **주방** | 밀폐용기·주방정리·소도구·키친타올·식기 | 반복구매↑, 정리 before/after 영상성↑ | 발견형 / TOP3 / 묶음 |
| **청소·정리** | 무선청소기·정리함·수납·틈새청소·먼지제거 | 객단가↑(청소기), 만족도 후기↑ | 문제-해결 / TOP3 |
| **욕실** | 샤워필터·수건·수전·욕실수납·발매트 | before/after 극적, 저가~중가 | 문제-해결 / 발견형 |
| **생활잡화·전기** | 멀티탭·조명·건전지·행거·옷걸이·수납 | 필수템, 낮은 구매저항 | 발견형 / 묶음 |
| **계절·시즌** | (겨울)가습기·전기요·손난로 / (여름)제습·모기·선풍기 | 수요 폭발 타이밍 | 리스트 / 문제-해결 |

**핵심 인사이트:** 
- **미끼(클릭 유도)** = 저가·발견형("이거 3천원인데 미쳤어요") → 클릭률↑
- **객단가 상승** = 묶음·리스트("자취 필수 5종") + 세션 내 무선청소기 같은 고가템 노출 → 커미션↑
- 이 둘을 **한 콘텐츠 안에서 결합**하는 게 400만원 목표의 핵심.

## 3. 검증용 시드 리스트 (쿠팡 베스트100에서 확인 후 채우기)

> ⚠️ 아래는 **콘텐츠화가 유리한 "상품 유형" 후보**입니다. 실제 SKU·가격·순위·수수료율은 [쿠팡 베스트100](https://www.coupang.com/np/best100/bestseller)과 파트너스 대시보드에서 **직접 확인 후** §1 스코어표로 검증하세요. (가격/순위는 실시간 변동)

### 🥇 즉시 테스트 후보 (영상성 + 문제해결 강함)
| 상품 유형 | 왜 유망한가 | 포맷 |
|------|------|------|
| 주방 밀폐용기 세트 | 냉장고 정리 before/after = 강력한 영상 | 묶음/발견형 |
| 틈새·틈새청소 도구 | "여기 이렇게 더러웠어?" 극적 대비 | 문제-해결 |
| 샤워 필터 | 녹물 차단 = 즉각적 공감·불안 자극 | 문제-해결 |
| 무선 핸디청소기 | 객단가↑ + 만족도 후기↑ | TOP3 비교 |
| 케이블·멀티탭 정리 | "책상 뒤 지옥" 공감 → 저장각 | 발견형 |
| 실리콘 주방소도구 | 저가·비주얼·충동구매 | 발견형 |

### 🥈 시즌 대기 후보 (캘린더 연동)
| 시즌 | 상품 유형 |
|------|------|
| 초가을~겨울(지금 준비) | 가습기, 전기요/온수매트, 손난로, 제습·결로 방지 |
| 봄 | 청소·대청소템, 미세먼지·공기청정 필터 |
| 여름 | 제습기, 모기퇴치, 서큘레이터, 쿨매트 |

> **지금(7월말) = 여름 막바지 + 가을·겨울 시즌 선점 타이밍.** 가습기·전기요 콘텐츠를 미리 쌓아두면 수요 폭발기에 검색·추천을 선점.

## 4. 세션 객단가 극대화 — 묶음 조합 설계 (400만원 레버)

세션 객단가를 2.5만 → 4만으로 올리면 필요 조회수가 40% 줄어듭니다(플랜 §8). 방법 = **"하나 사면 나머지도 사게" 묶음 콘텐츠.**

**묶음 콘텐츠 공식:** `테마 1개 + 상품 3~5개 + "풀세트로 갖추면" CTA`

예시 테마:
- "자취 첫날 이것만 있으면 됨 5종" (밀폐용기+멀티탭+행거+청소도구+수건)
- "주방 정리 끝판왕 세트" (밀폐용기+수납+소도구)
- "욕실 새것처럼 만드는 4가지" (샤워필터+수건+수납+발매트)
- "겨울나기 필수 5종" (가습기+전기요+손난로+문풍지+슬리퍼)

→ 한 영상에서 여러 링크 노출 + 세션 내 복수 구매 유도. **리스트/묶음 포맷을 전체 발행의 30~40%로 유지.**

## 5. 매주 반복 리서치 SOP (자동화 연동 · 주 30분)

하루 1시간 제약 하에서 리서치는 **주 1회 30분 배치**로 처리하고, 자동화가 초안을 만듭니다.

```
[주간 리서치 루틴 — 자동화 초안 + 사람 검수]
1. (자동) 쿠팡 베스트100 생활용품 + 카테고리별 급상승 스캔 → Claude가 후보 20개 추출
2. (자동) 각 후보를 §1 스코어표로 채점 → 13점+ 만 선별
3. (자동) 경쟁 스캔: 유튜브/틱톡에 해당 상품 숏폼이 이미 포화인지 체크
4. (사람, 15분) 상위 후보 검수 → 이번 주 제작할 상품 5~7개 확정
5. (사람, 15분) 각 상품에 포맷 배정 + 묶음 조합 결정
6. (자동) 확정 상품 → 대본·영상·썸네일 파이프라인으로 전달
```

> **자동화 수단:** Make.com 시나리오(스캔·집계) + Claude(스코어링·대본) + Notion(후보 DB). 이 세션에서 실제 시나리오를 구축할 수 있습니다.

## 6. 피해야 할 상품 (전환·정책 리스크)

- ❌ **판매자배송·배송느림** — 충동구매 타이밍 놓침
- ❌ **리뷰 적거나 평점 낮음** — 전환율·신뢰 붕괴
- ❌ **초저가(수백원~천원대) 단독** — 수수료 미미 (묶음 미끼로만 활용)
- ❌ **고가·고관여(수십만원 가전)** 단독 소구 — 숏폼 충동구매와 안 맞음 (세션 노출로만)
- ❌ **과장·허위 소구** — 공정위·플랫폼 정책 위반 → 계정 리스크. 단점도 정직하게.
- ❌ **의약외품·건강 효능 주장** — 표현 규제 강함, 초보 리스크 회피
