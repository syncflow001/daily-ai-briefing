# 벤치마크 — 쿠파스(쿠팡파트너스) 숏폼 고수 발굴 & 분해

> **목적:** 인스타·유튜브·틱톡·스레드에서 잘하는 쿠팡파트너스 크리에이터를 ① 직접 찾고 ② 분해해서 우리 파이프라인에 이식
> **버전:** v1 · 2026-07-28
> **주의:** 플랫폼 내부 데이터는 스크래핑 차단(403)으로 자동 수집 불가 → 아래 "발굴 플레이북"으로 직접 찾는 방식이 정석. 확인 안 된 계정 핸들은 이 문서에 싣지 않음(허위 방지).

---

## 1. 실제 확인된 사례 (검색으로 검증된 것만)

> 특정 개인 채널명은 대부분 익명 처리돼 있으나, **수익 규모·방식·발행 패턴**은 벤치마크로 유효합니다.

| 사례 | 규모/성과 | 방식 | 시사점 |
|------|------|------|--------|
| 직장인 쇼츠 부업 사례 (다음뉴스) | 9개월차 월 **950만원**, 9월 4일 만에 472만원 | 쇼츠 타겟팅 최적화 | **9개월 = 궤도 진입 시점.** 우리 6개월 체크포인트와 정합 |
| "쇼츠 채널 10개, 월 8,000만원" (유튜브) | 다계정 운영 | 채널 **10개 분산** 운영 | 단일계정 천장 → **다계정 = 후반 확장 전략**(플랜 §10 Q4) |
| "무자본 쇼핑쇼츠 월 1000만원?" (유튜브) | 무자본 | 쇼핑 쇼츠 | 광고비 0 모델 검증 |
| 크몽 노하우 판매 | 유튜브 **2달 만에 월 180만원** | 쿠팡파트너스 쇼츠 | **초기 3개월 내 첫 유의미 수익 가능** 증거 |

**교차 결론:** 
- 초기 2~3개월에 소액 수익 → 6~9개월에 궤도 진입이 현실적 곡선. 우리 마일스톤 사다리(§8)와 일치.
- 상위권은 **다계정·다발행**으로 조회수 복권을 대량 구매. 우리 자동화 파이프라인의 존재 이유.

## 2. 고수 발굴 플레이북 (플랫폼별 — 직접 실행)

자동 수집이 막혀 있으니, 아래 방법으로 **본인이 직접** 워치리스트를 채우세요. 주 1회 15분.

### 📸 인스타그램
- **해시태그 탐색:** `#쿠팡추천` `#생활꿀템` `#자취템` `#살림템` `#쿠팡파트너스` → "인기 게시물" 상단 = 참여율 높은 계정
- **릴스 탭:** 위 키워드 검색 → 릴스 정렬 → 조회수 높은 순으로 계정 역추적
- **판별법:** 프로필 링크가 링크인바이오(리틀리/인포크링크)이고 공정위 문구가 있으면 = 쿠파스 계정
- **팔로우 힌트:** 한 고수를 찾으면 그 계정의 "추천/유사 계정"이 줄줄이 나옴

### ▶️ 유튜브(쇼츠)
- **검색:** `생활용품 추천` `살림꿀템` `이거 왜 이제 알았지` + 필터 → 쇼츠 / 조회수순
- **판별법:** 설명란·고정댓글에 쿠팡 링크(`link.coupang.com`) + 공정위 문구
- **채널 분석:** 채널 홈 → 인기 동영상 정렬로 **어떤 상품 영상이 터졌는지** 확인
- **케이스 영상 참고:** "쇼츠 채널 10개 월 8000만원", "무자본 쇼핑쇼츠" 류 인터뷰에서 실전 노하우 채굴

### 🎵 틱톡
- **디스커버/검색:** `쿠팡파트너스 꿀템` `생활꿀템` `자취템` → 조회수 상단
- **Top 영상 분석:** 초반 1초 훅·자막 스타일·BGM 패턴
- **신규계정 우대 관찰:** 팔로워 적은데 조회수 터진 영상 = 최신 먹히는 포맷 신호

### 🧵 스레드
- **검색:** `쿠팡 파트너스` `생활꿀템` `살림템` → 참여(좋아요·리포스트) 높은 글
- **판별법:** 본문/댓글 쿠팡 링크 + "(광고) 이 포스팅은 쿠팡 파트너스 활동의 일환..." 문구
- **텍스트훅 채굴:** 스레드는 텍스트 훅의 보고 → 잘 걸리는 첫 문장 패턴 수집

## 3. 벤치마크 분해 템플릿 (발굴한 계정마다 작성)

찾은 고수를 이 표로 분해 → 우리 파이프라인에 이식.

```
계정: @__________  (플랫폼: ____)  팔로워/구독: ______
─────────────────────────────────────────
1. 훅(첫 1~2초): 어떤 말/자막/장면으로 스크롤을 멈추나?
2. 포맷: 문제해결 / 발견형 / TOP3 / 공감 / 묶음 중?
3. 영상 구조: (훅 → 문제 → 상품 → 사용컷 → CTA) 몇 초씩?
4. 자막 스타일: 폰트·색·위치·강조 방식
5. BGM/사운드: 트렌드 사운드 사용 여부
6. 상품군: 어떤 생활용품 카테고리에 집중?
7. 객단가대: 저가 미끼 / 중가 / 묶음?
8. 프로필: 소개문구·링크 버튼 카피
9. 링크구조: 링크인바이오 툴? 상품별 정리 방식?
10. CTA: "저장/프로필 링크" 어떻게 유도?
11. 발행 빈도: 하루 몇 개? 시리즈 있나?
12. 터진 영상 TOP3: 공통점은?
─────────────────────────────────────────
→ 우리가 훔칠 것 1~3개:
→ 우리가 다르게 할 것:
```

> 이 템플릿을 Notion DB로 만들면 자동화 파이프라인의 "리서치·기획" 단계에 연결 가능 (이 세션에서 구축 지원).
