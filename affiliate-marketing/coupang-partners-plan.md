## 1. 익스큐티브 서머리 *(60초 요약)*

**한 줄 정의:** AI 완전 자동화 파이프라인으로 faceless 생활용품 숏폼을 **4채널에 매일 대량 발행**하고, 하루 1시간은 오직 검수·의사결정에만 쓰는 1인 쿠팡파트너스 사업.

### 3대 베팅 (Big Bets)

1. **"제작"이 아니라 "검수"만 한다 — 완전 자동화 파이프라인이 경쟁력의 전부.** 하루 1시간 제약 하에서 발행량을 내는 유일한 길. 리서치→대본→영상→썸네일→업로드를 AI+Make.com으로 잇고, 사람은 승인 버튼만 누른다. (§11)
2. **생활용품 = 반복구매·낮은 구매저항·로켓배송의 3박자.** 충동구매가 쉽고 객단가 1~5만원대라 세션 전환이 빠르다. "몰랐던 살림꿀템" 발견형 콘텐츠가 저장·공유·구매를 동시에 유발.
3. **발행량으로 조회수 복권을 산다.** 숏폼은 소수 대박이 전체 수익을 만든다. 4채널 × 매일 = 타석 수 극대화. 바이럴 1편 나오면 즉시 변주 양산.

### 90일 우선순위

- **완전 자동화 파이프라인 v1 구축** (1편 사람 개입 ≤ 5분, 하루 총 1시간 내 다편 승인)
- **하루 다편 × 4채널 발행 리듬** 확립 (원본 1편 → 4채널 리퍼포징)
- **어트리뷰션 세팅** → "어떤 콘텐츠가 실제 커미션이 되는지" 측정 시작 → 승자 더블다운

### 12개월 아웃컴

- **North-star: 월 커미션 400만원** (스트레치) / **현실 base 100~200만원** (§8 사다리)
- 검증된 faceless 포맷 5종 + AI 프롬프트/자동화 시나리오 **자산화**
- 바이럴 재현이 가능한 **반복 시스템** 완성 (2번째 니치 확장 준비)

## 2. 전략적 프레임

### 카테고리 주장
"쿠팡 링크 뿌리는 계정"이 아니라 **"살림/생활 고민을 해결하는 꿀템 큐레이터"**. 상품은 해결책의 증거.

### ICP — 타깃 시청자
숏폼 스크롤 중 **"이거 우리집에 필요한데?"** 하고 멈추는 사람.
- 자취·신혼·육아·1인가구 등 **생활 밀착 소비층**
- 객단가 1~5만원, **로켓배송 즉시구매**에 반응 (충동구매 저항 낮음)
- 저장("나중에 살 것")·공유("이거 봐봐") 행동이 자연스러운 층

### 비즈니스 모델 로직 (돈이 나오는 구조)
```
조회수(무료·알고리즘)  →  링크 클릭  →  쿠팡 세션 진입  →  세션 내 구매  →  커미션(3%)
   ↑ 자동화로 발행량↑      ↑ 훅·CTA↑     ↑ 로켓배송·꿀템    ↑ 세션 객단가↑
```
**핵심 레버 4개:** ① 발행량(조회 기회) ② 링크 CTR(훅/CTA) ③ 전환율(상품 매력) ④ **세션 객단가**(쿠팡은 클릭 후 세션 내 다른 구매분에도 커미션 → 이게 숨은 승부처). 광고비 0으로도 성립.

### 브랜드 보이스 (타협 불가)
- **정직한 큐레이터** — 단점도 언급. 장기 신뢰 = 전환율의 복리 자산.
- **공정위 문구 100%** — 모든 게시물에 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." (신뢰 + 법적 필수)
- **AI로 만들되 사람 냄새** — faceless여도 톤은 친근한 옆집 언니/형처럼. AI 티 나는 기계 음성·번역투 금지.

## 4. Acquisition — 도달시키기

**목표:** 4채널 알고리즘 추천으로 조회수 확보. 퍼널 입구 = 최우선 투자처.

### 채널 전략 (원본 1편 → 4채널 리퍼포징)

| 채널 | 역할 | 링크 처리 |
|------|------|-----------|
| **유튜브 쇼츠** | 검색·롱테일 지속 유입 (평생 검색됨) | 설명란 + **고정댓글** |
| **인스타 릴스** | 저장·공유 강함, 링크인바이오 | 캡션 링크 불가 → **링크인바이오** |
| **틱톡** | 초기 도달·바이럴 확률 높음 (신규계정 우대) | 프로필 링크 / 링크인바이오 |
| **스레드** | 텍스트훅·커뮤니티·빠른 실험 | 본문/댓글 (도배 주의) |

> faceless 4채널 리퍼포징은 자동화의 정확히 그 지점. 원본 세로영상 1개 → 워터마크/비율만 조정해 4곳 배포.

### faceless 포맷 5종 (생활용품 특화)
1. **문제-해결형** — "이 불편, 이거 하나면 끝" (제품 B롤 + AI보이스 + 자막)
2. **발견형** — "이거 왜 이제 알았지" 살림꿀템 소개
3. **TOP3 비교** — "OO 3천원 vs 3만원 차이" (전환 우수 포맷)
4. **상황·공감형** — "자취 3년차만 아는 그 순간" (밈/공감 → 공유↑)
5. **묶음/리스트형** — "겨울 필수템 5가지" (세션 객단가↑ → 커미션↑)

### 90일 무브
1. **훅 라이브러리 20종** AI 생성 → CTR 테스트 → 승자 패턴화 (`ad-creative`, `copywriting`)
2. **하루 다편 × 4채널** 발행 (자동화가 가능케 함)
3. **쇼츠 검색 SEO** — 상품·문제 키워드를 제목/자막에 (`seo-audit` 응용)
4. **틱톡 초기 우대** 활용 — 신규계정 도달 보너스 구간에 집중 발행

### 12개월 무브
- 조회 데이터로 **승자 서브토픽 2~3개** 발굴 → 시리즈화
- 바이럴 1편 → **즉시 변주 5편 양산** (모멘텀 활용)
- 검증 후 소액 부스팅 테스트 (예비예산 5만 내, `ads`)

### 실행 스킬
`ad-creative` · `copywriting` · `social` · `content-strategy` · `video` · `image`

## 5. Activation — 클릭시키기

**목표:** 조회 → 프로필 → **링크 클릭 → 쿠팡 세션 진입**. 여기서 새면 수익 0.

### 핵심 무브
1. **프로필 = 랜딩페이지.** 소개에 "무엇을 해결하는 계정"인지 + 링크 버튼 행동유도("👇 오늘 꿀템 보러가기"). (`cro`)
2. **링크인바이오 구조화.** 리틀리/링크트리에 **최근 소개 상품별 링크** + 대표 큐레이션. 영상마다 "프로필 링크" CTA 통일.
3. **영상 내 CTA.** 마지막 2초 "저장하고 프로필 링크 확인" 고정. 쇼츠는 고정댓글 안내.
4. **쿠팡 딥링크.** 정확한 상품 페이지 착지 = 마찰 최소화. **로켓배송 우선** = 즉시 구매.

### 측정
링크 클릭수·쿠팡 유입·클릭률을 주간 추적 → "돈 되는 조회수" 식별.

### 실행 스킬
`cro` · `signup`(프로필 최적화 응용) · `analytics`

## 6. Retention — 오디언스를 자산화

**목표:** 팔로워가 반복 노출·반복 구매. 신규 도달보다 저렴한 자산.

### 핵심 무브
1. **발행 일관성 = 최고의 리텐션.** 요일 시리즈("월요일 살림템", "금요일 가성비 TOP3")로 기대감 형성.
2. **"저장각" 정보 콘텐츠** — 체크리스트/꿀팁 → 저장률↑ → 알고리즘 신호↑ + 재방문↑.
3. **댓글·DM 응대** — 상품 문의 성실 응대 → 신뢰 → 재구매. AI FAQ 초안 + 사람 마무리.
4. **스레드 커뮤니티화** — 설문·대화로 다음 소재 발굴 + 결속.

### 실행 스킬
`community-marketing` · `emails`/`sms`(추후 오픈채팅·뉴스레터 확장) · `social`

## 7. Referral — 시청자가 시청자를 데려오게

**목표:** 숏폼의 진짜 성장 엔진 = 공유/저장/태그. 알고리즘이 공유율을 강력 추천 신호로 사용.

### 핵심 무브
1. **"공유각" 설계** — "이거 친구한테 보여줘야 해" 유발 (놀라운 가성비, 몰랐던 꿀템, 공감 상황). 기획 시 "이걸 누구에게 보낼까?" 자문.
2. **태그 유도 CTA** — "자취하는 친구 소환" → 도달 확장.
3. **저장 유도** — 지연 전환 + 알고리즘 부스트.
4. **UGC 리포스트**(후기 확보 시) — 사회적 증거.

### 실행 스킬
`referrals` · `marketing-psychology` · `community-marketing`

## 8. Revenue — 400만원 목표 역산 & 커미션 극대화

### ⚠️ 목표 역산 (냉정한 현실 점검)

`커미션 = 조회수 × 링크CTR × 전환율 × 세션객단가 × 수수료율`

**월 400만원을 3% 수수료로 역산하면:**

| 단계 | 가정 | 필요치 |
|------|------|--------|
| 월 커미션 | 목표 | 400만원 |
| ÷ 수수료율 | 3% | **월 거래액 1.33억원** |
| ÷ 세션 객단가 | 2.5만원 | 월 주문 5,320건 (일 177건) |
| ÷ 전환율 | 4% | 일 클릭 4,430 |
| ÷ 링크 CTR | 1% | **일 조회 약 44만 (월 1,330만 조회)** |

**해석:** 월 1,330만 조회는 **상위 성과 구간**입니다. 불가능하진 않지만(생활용품 상위 계정은 도달) 12개월 내 median 결과는 아닙니다. **정직하게 말하면 400만원은 스트레치 목표**입니다.

**하지만 레버를 움직이면 필요 조회가 급감합니다:**
- 세션 객단가 2.5만 → **4만**(묶음/리스트 콘텐츠, 로켓와우 세션구매)이면 필요 조회 **약 40% 감소**
- 전환율 4% → **7%**(로켓배송·검증상품 집중)이면 추가 급감
- 두 레버 동시 개선 시 필요 조회가 절반 이하로 → **월 500~600만 조회 수준**에서 400만원 달성 가능

→ **전략적 결론: 조회수 경쟁만으로 400만원은 힘들다. "세션 객단가 × 전환율"을 끌어올리는 상품·콘텐츠 설계가 진짜 승부처.**

### 현실적 마일스톤 사다리 (월 커미션)

| 시점 | Base(현실) | Target | Stretch |
|------|:---:|:---:|:---:|
| 3개월 | 첫 커미션~10만 | 20만 | 50만 |
| 6개월 | 30~50만 | 80만 | 150만 |
| 9개월 | 80~120만 | 200만 | 300만 |
| **12개월** | **100~200만** | **300만** | **400만** ✅목표 |

> 400만원은 **12개월 스트레치**로 조준하되, 6개월 시점에 궤도(월 80만+ & 우상향)를 확인하는 게 핵심 체크포인트. 미달 시 니치·포맷 피벗 판단.

### 커미션 극대화 레버
1. **세션 객단가↑** — 묶음/리스트 콘텐츠로 "장바구니 채우기" 유도. 쿠팡 세션 구매 특성의 정면 활용.
2. **전환율↑** — 로켓배송 + 리뷰 많고 평점 높은 검증 상품만.
3. **시즌·세일 캘린더** — 쿠팡 빅세일·명절·계절템 타이밍 집중.
4. **수익 콘텐츠 더블다운** — 실제 커미션 발생 유형을 데이터로 식별 → 집중.

### 수수료 주의
수수료율은 카테고리별 상이·정책 변동. **정확값은 쿠팡파트너스 공지 확인** 후 추정에 반영. (본 문서는 보수적 3% 가정)

### 실행 스킬
`offers`(묶음·시즌) · `pricing`(객단가·믹스) · `attribution`

## 13. 측정 · RACI · 부록

### 노스스타 지표
**월 쿠팡 커미션.** 초기 3개월은 선행지표 집중(수익은 후행).

### 단계별 선행지표
| 단계 | 지표 |
|------|------|
| Acquisition | 조회수, 도달, 신규 팔로워, 발행 편수 |
| Activation | 프로필 방문율, 링크 클릭수, 쿠팡 유입 |
| Retention | 팔로워 유지율, 저장률, 재방문 |
| Referral | 공유수, 태그·댓글 |
| Revenue | 전환율, **세션 객단가**, 커미션 |

### RACI (1인 사업이라 단순)
- **본인:** 모든 항목의 A/R. 단, 하루 1시간은 **검수·승인·의사결정**에만.
- **AI 파이프라인:** 모든 제작의 실행 담당(위임).
- **주간 30분:** 데이터 리뷰 + 승자 더블다운 결정.

### 남은 확인 항목 (실행 중 확정)
1. **쿠팡 수수료율·어트리뷰션 실규정** — 파트너스 공지 확인 (수익 추정 정밀화)
2. **AI 영상 생성 툴 선정** — faceless 생활용품 B롤에 맞는 툴 1~2개 확정
3. **6개월 궤도 체크포인트** — 월 80만+ 미달 시 니치/포맷 피벗 기준 사전 합의

### 부록 — 다음에 깊게 팔 스킬
- 콘텐츠 양산: `ad-creative` · `copywriting` · `video` · `image`
