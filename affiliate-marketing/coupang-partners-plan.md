# AI 제휴마케팅 종합 플랜 — 쿠팡파트너스 × 숏폼(인스타·쇼츠·스레드)

> **작성 관점:** fCMO(프랙셔널 CMO) 수준의 12개월 실행 로드맵
> **구조:** AARRR(Acquisition·Activation·Retention·Referral·Revenue) — 각 실행안은 퍼널 단계로 태깅
> **버전:** v1 (초안) · 최종 수정 2026-07-28
> **상태:** 리소스·예산·목표 일부는 가정값 — §13 「열린 결정사항」에서 확정 필요

---

## 0. 이 플랜을 읽는 법

일반적인 마케팅 플랜은 "채널 → 전술" 순서로 나열됩니다. 이 플랜은 **AARRR 퍼널 단계**로 묶습니다. 이유는 단순합니다 — 제휴마케팅에서 **돈은 퍼널의 맨 끝(쿠팡 구매)에서 나오지만, 병목은 대부분 앞단(도달·클릭)에 있기** 때문입니다. 단계별로 태깅하면 "지금 무엇을 먼저 고쳐야 하는지"가 우선순위대로 드러납니다.

**제휴 크리에이터 관점의 AARRR 재해석:**

| 단계 | 일반 SaaS | **이 프로젝트(쿠팡파트너스 숏폼)** |
|------|-----------|------------------------------------|
| **Acquisition** | 방문자 유입 | 릴스·쇼츠·스레드 **노출/도달/조회수** (알고리즘 추천) |
| **Activation** | 가입·온보딩 | 프로필 방문 → **팔로우 + 링크인바이오 클릭 → 쿠팡 랜딩** |
| **Retention** | 재사용 | 팔로우 유지·재방문·저장·알림 설정 (**내 오디언스 = 자산**) |
| **Referral** | 추천 프로그램 | **공유·저장·친구 태그** (숏폼의 진짜 성장 엔진) |
| **Revenue** | 결제·업셀 | **쿠팡 커미션** (전환율 × 객단가 × 카테고리 믹스) |

**크로스커팅(모든 단계 관통):** ① 계정 브랜드/페르소나 ② AI 콘텐츠 생산 파이프라인. 이 둘은 단독 단계가 아니라 5단계 전부에 영향을 줍니다.

## 1. 익스큐티브 서머리 *(60초 요약)*

**한 줄 정의:** AI로 숏폼 제작 단가를 극단적으로 낮춰, **인스타·쇼츠·스레드 3채널에 매일 발행**하고, 팔로워를 쿠팡 구매로 전환시키는 1인 제휴마케팅 사업.

### 3대 베팅 (Big Bets)

1. **AI 콘텐츠 파이프라인으로 "발행량"을 무기화한다.** 숏폼은 조회수 분포가 극단적(대부분 死, 소수 대박)이라 **타석 수 = 성공 확률**. AI로 하루 1편이 아니라 3~9편(채널×리퍼포징)을 감당한다. → *경쟁 우위의 핵심.*
2. **"단일 상품 리뷰"가 아니라 "문제-해결 큐레이션"으로 포지셔닝한다.** 쿠팡 링크를 파는 게 아니라 **"이 문제엔 이 물건"** 이라는 신뢰를 판다. 팔로워(자산)를 쌓아야 링크가 팔린다.
3. **한 계정에 올인하지 않고 니치 검증 후 확장한다.** 초기 4~6주는 니치·훅·포맷을 **저비용으로 실험**, 데이터로 승자를 고른 뒤 자원을 집중한다.

### 90일 우선순위

- **니치 1개 확정 + 계정 브랜딩 + AI 파이프라인 구축** (콘텐츠 1편 생산 리드타임 30분 이하로)
- **하루 최소 1편 × 3채널 발행 리듬** 확립 (릴스 원본 → 쇼츠·스레드 리퍼포징)
- **링크인바이오 + 어트리뷰션 세팅**으로 "어떤 콘텐츠가 실제 돈이 되는지" 측정 시작

### 12개월 아웃컴 (목표 — §13에서 수치 확정)

- 주력 채널 팔로워 **1만+** & 월 안정적 쿠팡 커미션 확보
- 검증된 **콘텐츠 포맷 5종** 라이브러리화 (AI 프롬프트 자산화)
- 2번째 니치/계정으로 확장 가능한 **반복 가능한 시스템** 완성

## 2. 전략적 프레임

### 카테고리 주장 (어떻게 인식되고 싶은가)
"쿠팡 링크 뿌리는 계정"이 아니라 **"○○ 고민을 해결해주는 큐레이터"**. 상품은 해결책의 증거일 뿐. (니치는 §13에서 확정)

### ICP — 타깃 시청자
숏폼을 스크롤하다 **"어 이거 나한테 필요한데?"** 하고 멈추는 사람. 구체적으로:
- 특정 생활 고민/욕구를 가진 층 (예: 자취 살림, 육아템, 캠핑, 주방, 가성비 테크 등 — 니치 확정 시 구체화)
- **충동구매 저항이 낮고 객단가 1~5만원대** 상품에 반응하는 층 (쿠팡 로켓배송 = 즉시 구매 전환 유리)

### 비즈니스 모델 로직 (돈이 나오는 구조)
```
조회수(무료·알고리즘)  →  프로필/링크 클릭  →  쿠팡 방문  →  세션 내 구매  →  커미션
    ↑ AI로 발행량↑        ↑ 훅·CTA 최적화     ↑ 상품매력    ↑ 로켓배송·객단가
```
핵심 레버: **① 발행량(=노출 기회) ② 클릭률(=훅/CTA) ③ 전환·객단가(=상품 선정).** 이 셋의 곱이 수익. 광고비 0으로도 성립하는 게 이 모델의 장점.

### 브랜드 보이스 (타협 불가 원칙)
- **정직한 큐레이터.** 단점도 말한다 → 장기 신뢰 = 클릭률/전환율의 복리 자산.
- **공정위 문구 100% 준수.** 모든 게시물에 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." 명시. (신뢰 + 법적 필수)
- **AI로 만들되 AI 티는 안 나게.** 대본·리서치는 AI, 하지만 톤은 사람 냄새.

## 4. Acquisition — 낯선 사람을 도달시키기

**목표:** 릴스·쇼츠·스레드 알고리즘의 추천을 받아 조회수를 확보한다. 이 단계가 전체 퍼널의 깔때기 입구 = **최우선 투자처.**

### 채널 전략

| 채널 | 역할 | 포맷 | 링크 처리 |
|------|------|------|-----------|
| **인스타 릴스** | 메인 도달 엔진 | 15~40초 세로 영상 | 캡션 링크 불가 → **링크인바이오** |
| **유튜브 쇼츠** | 검색·롱테일 지속 유입 | 릴스 리퍼포징 | 설명란 + **고정댓글** 링크 |
| **스레드** | 텍스트훅·커뮤니티·빠른 실험 | 짧은 글/이미지 + 영상 | 본문/댓글 링크 (도배 주의) |

> **원본 1편 → 3채널 리퍼포징**이 기본 원칙. 릴스로 만들고 워터마크만 정리해 쇼츠에 올리고, 핵심 메시지를 스레드 텍스트로 변주.

### 90일 무브

1. **훅 라이브러리 구축** — 숏폼 성패의 80%는 첫 1~2초. AI로 훅 20종 생성 → 테스트 → 승자 패턴화. (`ad-creative`, `copywriting` 스킬)
2. **포맷 5종 실험** — ① 문제-해결 ② "이거 왜 이제 앎" 발견형 ③ TOP3 비교 ④ 언박싱/사용컷 ⑤ 상황극/밈. 각 포맷 최소 5편씩 돌려 CTR·조회수로 승자 선별.
3. **발행 리듬** — 최소 하루 1원본 × 3채널. 주 5~7일. (AI 파이프라인이 이걸 가능케 함 → §11)
4. **해시태그·키워드 SEO** — 쇼츠는 검색 유입이 크다. 상품·문제 키워드를 제목/설명에 심기. (`seo-audit` 개념 응용)

### 12개월 무브
- 조회수 데이터로 **니치 내 승자 서브토픽** 2~3개 발굴 → 시리즈화
- 검증되면 **소액 부스팅/광고 테스트** (예산 열리면 — `ads` 스킬)
- 바이럴 1편 나오면 **즉시 유사 변주 5편** 양산 (알고리즘 모멘텀 활용)

### 실행 스킬·툴
`ad-creative`(훅·변주) · `copywriting`(대본) · `social`(채널운영) · `video`/`image`(제작) · `content-strategy`(주제) · `naver-keyword-strategy`(키워드 응용)

## 5. Activation — 시청자를 "클릭"시키기

**목표:** 조회 → 프로필 방문 → **팔로우 + 링크 클릭 → 쿠팡 랜딩**. 조회수가 아무리 높아도 여기서 새면 수익 0.

### 핵심 무브

1. **프로필 = 랜딩페이지.** 한 줄 소개에 "무엇을 해결해주는 계정인지" 명확히. 링크인바이오 버튼에 **행동 유도 문구**("👇 오늘 소개한 상품 보러가기"). (`cro` 스킬 응용)
2. **링크인바이오 구조화.** 리틀리/링크트리 등에 **최근 소개 상품별 링크 정리** + 대표 큐레이션. 영상마다 "프로필 링크에서 확인" CTA 통일.
3. **영상 내 CTA 설계.** 마지막 2초에 "저장하고 프로필 링크 확인" 고정. 쇼츠는 고정댓글 링크 안내.
4. **쿠팡 랜딩 최적화.** 딥링크로 **정확한 상품 페이지**에 착지 (탐색 마찰 최소화). 로켓배송 상품 우선 = 즉시 구매 전환 유리.

### 측정
- **클릭률(프로필→링크)**, 링크인바이오 클릭수, 쿠팡 유입수를 주간 추적 → 어떤 콘텐츠가 "돈 되는 조회수"인지 식별.

### 실행 스킬·툴
`cro`(전환) · `signup`(프로필 최적화 응용) · 링크인바이오 툴 · 쿠팡파트너스 딥링크 · `analytics`

## 6. Retention — 오디언스를 자산으로 쌓기

**목표:** 팔로워가 떠나지 않고 **반복 노출·반복 구매**하게 한다. 제휴마케팅에서 팔로워는 "다시 판매할 수 있는 자산". 신규 도달보다 저렴하다.

### 핵심 무브

1. **발행 일관성 = 최고의 리텐션.** 알고리즘·팔로워 모두 꾸준함에 보상. 요일별 시리즈(예: "월요일 살림템", "금요일 가성비 TOP3")로 **다음 콘텐츠를 기대하게** 만들기.
2. **저장·팔로우 유도 콘텐츠.** "저장각" 정보형 콘텐츠(체크리스트/꿀팁)로 저장률↑ → 알고리즘 신호↑ + 재방문↑.
3. **댓글·DM 응대 = 관계.** 상품 문의에 성실 응대 → 신뢰 → 재구매. AI로 FAQ 초안, 사람이 마무리.
4. **스레드로 커뮤니티화.** 스레드는 텍스트 소통에 강점 → 팔로워와 대화·설문으로 다음 콘텐츠 소재 발굴 + 결속.

### 실행 스킬·툴
`emails`/`sms`(추후 뉴스레터·오픈채팅으로 확장) · `community-marketing`(스레드 커뮤니티) · `social`

## 7. Referral — 시청자가 시청자를 데려오게

**목표:** 숏폼의 **진짜 성장 엔진 = 공유/저장/태그**. 알고리즘은 공유율을 강력한 추천 신호로 사용 → 무료 도달 폭발의 열쇠.

### 핵심 무브

1. **"공유각" 설계.** "이거 친구한테 보여줘야 해" 유발 콘텐츠 — 놀라운 가성비, 몰랐던 꿀템, 공감 상황극. 콘텐츠 기획 시 **"이걸 누구에게 보낼까?"** 를 항상 자문.
2. **태그 유도 CTA.** "○○한 친구 소환하세요" 댓글 유도 → 도달 확장.
3. **저장 유도.** 저장은 "나중에 살게" 신호 = 지연 전환 + 알고리즘 부스트.
4. **UGC·리그램 루프(후기 확보 시).** 팔로워 후기를 리포스트 → 사회적 증거 + 참여 동기.

### 실행 스킬·툴
`referrals` · `marketing-psychology`(공유 심리·사회적 증거) · `community-marketing`

---

## 8. Revenue — 커미션 극대화

**목표:** 같은 클릭에서 **더 많은 커미션**을 뽑는다. `커미션 = 클릭수 × 전환율 × 객단가 × 수수료율`.

### 핵심 레버

1. **상품 선정 = 수익의 절반.** 
   - **로켓배송** 상품 우선 (즉시 구매 = 세션 내 전환↑)
   - 리뷰 많고 평점 높은 검증 상품 (전환율↑ + 신뢰)
   - 객단가·수수료율 **카테고리 믹스** 관리 (저가 대량 + 중고가 간헐)
2. **세션 구매 특성 활용.** 쿠팡은 클릭 후 **세션 내 다른 구매분에도 커미션**이 붙는 특성 → "장바구니 채우는 시즌·묶음" 콘텐츠가 유리. *(정확한 정책은 쿠팡파트너스 공지 확인 — §13)*
3. **시즌·이벤트 캘린더.** 쿠팡 빅세일·명절·계절템 타이밍에 콘텐츠 집중 → 구매 의도 높은 시점 공략.
4. **수익 콘텐츠 더블다운.** 실제 커미션이 발생한 콘텐츠 유형을 데이터로 식별 → 그 포맷·카테고리에 자원 집중.

### 수수료 주의
쿠팡파트너스 수수료율은 **카테고리별 상이(대체로 최대 3%대)·실적 연동**이며 정책이 바뀝니다. **정확한 수치는 반드시 파트너스 공지에서 확인**하고 이 플랜의 수익 추정에 반영하세요.

### 실행 스킬·툴
`offers`(묶음·시즌 오퍼 기획) · `pricing`(객단가·카테고리 믹스 사고) · `attribution`(수익 귀속 분석)

## 13. 측정 · 오픈 결정 · 부록

### 노스스타 지표
**월 쿠팡 커미션 수익.** 단, 초기 3개월은 선행지표에 집중(수익은 후행).

### 단계별 선행지표
| 단계 | 지표 |
|------|------|
| Acquisition | 조회수, 도달, 신규 팔로워, 발행 편수 |
| Activation | 프로필 방문율, 링크 클릭수, 쿠팡 유입 |
| Retention | 팔로워 유지율, 저장률, 재방문 |
| Referral | 공유수, 태그·댓글, 바이럴 계수 |
| Revenue | 클릭→구매 전환율, 객단가, 커미션 |

### ⚠️ 열린 결정사항 (확정 필요 — 확정될수록 플랜 정확도↑)
1. **니치/카테고리** — 무엇을 큐레이션할지. *(가장 임팩트 큼 — 이게 정해져야 4~8절이 구체화됨)*
2. **운영 규모** — 완전 1인? 일부 외주?
3. **주간 투입 시간** — 발행량 목표의 상한을 결정.
4. **초기 예산** — 툴 구독 한도, 광고비 유무.
5. **12개월 수익 목표** — 구체 금액(월 ○○만원) → 역산 계획 가능.
6. **얼굴 노출 여부** — faceless AI형 vs 페르소나형 (파이프라인·포맷 달라짐).
7. **쿠팡 수수료·정책 실확인** — 카테고리별 수수료율, 어트리뷰션 정확 규정.
