### **Microsoft Build 2026 개막 — Project Polaris·Windows Agent Framework 공개** ([TechTimes](https://www.techtimes.com/articles/317596/20260602/github-copilot-replaces-gpt-4-project-polaris-ships-multi-agent-vs-code-build.htm)) · ([BuildFastWithAI](https://www.buildfastwithai.com/blogs/ai-news-today-june-2-2026))

6월 2~3일 개최된 Microsoft Build 2026에서 사티아 나델라 CEO는 "Windows는 더 이상 사람만을 위한 플랫폼이 아니다"라며 에이전트 퍼스트 전략을 선언했다. **Project Polaris**는 Microsoft가 자체 개발한 AI 코딩 모델로, 오는 8월부터 모든 GitHub Copilot 구독자의 기본 모델이 GPT-4 Turbo에서 Polaris로 교체된다. 코드 생성·멀티파일 리팩터링·테스트 작성·의존성 분석 등 개발 특화 MoE(전문가 혼합) 아키텍처로 설계됐다. 함께 발표된 **Windows Agent Framework(WAF) v1.0**은 MIT 라이선스로 오픈소스 공개돼, 로컬 Windows PC부터 Azure Arc 엣지 디바이스까지 동일한 YAML 매니페스트로 에이전트를 배포할 수 있다.

> 💡 **왜 중요한가**: Microsoft가 OpenAI 의존에서 벗어나 자체 AI 모델 생태계를 구축하는 결정적 신호로, GitHub·Azure·Office 전반에 걸친 AI 전략이 독자 노선으로 재편된다.

### Anthropic IPO와 AI 밸류에이션: $1조 시대의 의미

**배경·맥락**

Anthropic이 6월 1일 기밀 S-1을 제출하면서 AI 기업 공개(IPO) 레이스가 사실상 시작됐다. 2021년 설립 이후 Amazon·Google 등으로부터 총 $200억 이상을 유치하며 성장한 Anthropic은, 이번 $650억 시리즈 H 이후 밸류에이션이 $9,650억까지 치솟았다. 5월 기준 연간 매출 런레이트 $470억은 지난해 같은 시점($100억 추산) 대비 약 4.7배 성장한 수치다.

**시장·연구 측면의 영향**

이번 상장 시도는 몇 가지 구조적 변화를 시사한다. 첫째, AI 기업이 '비용 센터'에서 '수익 엔진'으로 전환하고 있다는 증거다. Anthropic이 예고한 6월 첫 흑자 분기는 대규모 컴퓨팅 비용을 상쇄할 만큼의 기업 구독·API 매출이 형성됐음을 의미한다. 둘째, Fortune이 '닷컴 버블 비교론'을 꺼낼 만큼 밸류에이션 논란이 거세지고 있다. $9,650억 밸류에이션 기준 PER(주가수익비율)을 계산하면 여전히 이익보다 기대치 프리미엄이 압도적이다. 셋째, OpenAI의 4분기 상장 전에 Anthropic이 먼저 시장을 선점하면 'AI 1세대 IPO' 프리미엄을 독점할 수 있다.

**앞으로 주목해야 할 관전 포인트**

- SEC 심사 과정에서 공개될 재무 구조: 컴퓨팅 비용·연구개발비·구독 매출 구성이 밸류에이션의 타당성을 가를 핵심이다

### Microsoft의 OpenAI 이탈: Project Polaris가 의미하는 것

**배경·맥락**

Microsoft Build 2026에서 공개된 Project Polaris는 단순한 모델 출시가 아니라, Microsoft가 수년간 구축한 OpenAI 의존 구조에서 벗어나는 전략적 선언이다. OpenAI에 대한 $130억 이상의 투자에도 불구하고, 모델 공급사를 자체 개발로 대체하는 결정을 내린 셈이다.

**시장·연구 측면의 영향**

Polaris가 GitHub Copilot의 기본 모델이 되면, 전 세계 수백만 명의 개발자가 매일 OpenAI 대신 Microsoft의 자체 모델을 사용하게 된다. WAF v1.0의 MIT 오픈소스 공개는 개발자 생태계를 Microsoft 에이전트 스택으로 유인하는 무료 온보딩 전략이다. 이는 AWS의 Bedrock·Anthropic 연합, Google의 Gemini 자체 생태계와의 3파전 구도에서 Microsoft가 독립 노선을 선언한 것으로 해석된다.

**앞으로 주목해야 할 관전 포인트**

- OpenAI와 Microsoft의 계약 조건 재협상 가능성: Polaris 전환 이후 양사 관계 변화
- Polaris의 실제 성능: GPT-4 Turbo 대비 코딩 벤치마크 결과가 8월 전환 성패를 좌우
- 한국 개발자 생태계 영향: GitHub Copilot 국내 사용자(기업 중심)의 Polaris 전환 경험과 피드백
